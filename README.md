# My personal Compte Rendu LaTeX Template
a LaTeX package for making compte Rendus with ease.
## Features
- Set up the page styles
- Add the packages (graphicx, amsmath, amsfonts, amssymb)
- Set up LaTeX macros:
    - \titlePage{Num_de_TP}{Matiere}{Nom_de_TP}{Binomes}{Enseignant}
    - \img[figure_props(width, height, ...)]{img_path}{figure_caption}
    - \eqsplit{} shorthand for equation enviroment with spit.
